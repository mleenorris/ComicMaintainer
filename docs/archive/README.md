# Historical Documentation Archive

Point-in-time write-ups from past development work: bug-fix post-mortems, implementation and
PR summaries, review guides, and test plans for specific changes.

**These documents are not maintained.** Each describes the state of the project at the time it
was written, and several describe the earlier Python implementation or subsystems that have
since been replaced. They are kept because they explain *why* particular decisions were made,
which is often not recoverable from the code alone — but they should never be treated as a
description of current behaviour.

This directory is deliberately not indexed file by file. Such a list went stale almost
immediately last time; use the file names, `git log`, or a search across the directory instead.

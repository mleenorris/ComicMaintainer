About Comic Maintainer

Comic Maintainer

Description

Comic Maintainer is a service that automatically watches a directory for new or changed comic archive files (.cbz/.cbr), tags them using ComicTagger, and manages duplicates. It provides a web interface for managing and processing comic files in your watched directory.

Settings

Appearance

Controls which view the library loads into when you first open the site.

Watcher

The file watcher automatically starts when either rename or normalize is enabled below. It monitors the directory for changes and automatically processes new or modified files based on your selected options.
When enabled, files will be renamed based on the filename template during processing.
When enabled, metadata will be normalized during processing.

Log Rotation

When the log file reaches this size, it will be rotated. Up to 3 backup files will be kept. Changes take effect on restart. Note: Can also be configured via the LOG_MAX_BYTES environment variable (in bytes).

Database Cleanup

How often the database should be cleaned of stale entries for files that no longer exist. Set to 0 to only run on startup. Changes take effect on restart. Recommended: 12 hours (default) or 24 hours for less frequent cleanup.
Manually trigger database cleanup to remove stale entries for files that no longer exist on disk.

Filename Format

Configure how files are renamed when processed. Use placeholders like {series}, {issue}, etc.

Available placeholders:
  • {series} - Series name
  • {issue} - Issue number (padded based on settings, default 4 digits, e.g., 0001, or 0071.4 for decimals)
  • {issue_no_pad} - Issue number (no padding, e.g., 1, or 71.4 for decimals)
  • {title} - Issue title
  • {volume} - Volume number
  • {year} - Publication year
  • {publisher} - Publisher name
Example: {series} v{volume} #{issue_no_pad} ({year})
Note: File extension (.cbz or .cbr) is automatically preserved
Current format:

Issue Number Padding

Controls how many digits the {issue} placeholder uses (default: 4). For example, with padding set to 4, issue 5 becomes 0005, with padding 3 it becomes 005, and with padding 0 it remains 5. Note: This only affects the {issue} placeholder. Use {issue_no_pad} for unpadded issue numbers regardless of this setting.

External Series Metadata

Master switch. When enabled, ComicMaintainer can look up alternate series titles from the providers configured below so variants can be grouped together in the series library view. Lookups are manual — use the Library page's Metadata → Refresh All External Metadata button or the per-series Manage Names action to populate the cache. Changes take effect after restart.

ComicVine (US comics)

Leave blank to disable ComicVine lookups. The key is stored in user settings on this instance.

MangaDex (manga)

Looks up canonical titles and alternate localizations from MangaDex. No API key required.

AniList

Queries AniList for both Manga (Japanese origin) and Manhwa (Korean origin). No API key required.
